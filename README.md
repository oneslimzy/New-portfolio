# Slimzy Concept — new design preview

A separate, from-scratch static website. Open index.html to preview it. The original website in the parent folder is untouched.

The layout uses a centred monochrome introduction, Video and Branding selected-work tabs, standalone case studies, six working benefits, FAQs and email/X/Telegram contact links. No showreel banner or Trusted By section.

Edit project content in projects.js. Copy and update one object to add a project. Case studies are generated by project.html and app.js. Put MP4s and cover images in assets/.

The video case-study descriptions were written after a direct visual review of the three finished films. Add verified client objectives, production credits or measurable results later if they become available. No fabricated testimonials, metrics, prices or turnaround promises are included.

Brand covers currently use existing public Behance image URLs. Complete projects link to the matching Behance case studies. For permanent hosting, locally stored project images are preferable. Videos and their existing frame captures are stored locally in assets/.
