# Slimzy Concept Portfolio

Static portfolio website for Slimzy Concept, built with HTML, CSS and JavaScript.

## Preview locally

Open `index.html` in a browser. `project.html` renders the individual video, brand identity, and campaign case studies using content from `projects.js`.

## Project content and media

- Update project descriptions, roles, and links in `projects.js`.
- Add project images and videos under `assets/` and reference them from `projects.js`.
- The site includes selected video, branding, and campaign work, project case studies, FAQs, and email, X, and Telegram contact links.
